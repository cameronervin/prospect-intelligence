# Grill me

Use for ambiguous or high-risk product scope. Read repository evidence first, then ask short rounds that materially change architecture or acceptance criteria.

Cover users and successful outcomes; data sources and retention; auth and tenancy; agent tools, approvals, and failure recovery; integrations and retries; evaluation population and thresholds; UX states; production ownership and rollback.

After each round, restate decisions, contradictions, and remaining blockers. Challenge vague terms with one concrete edge case. Stop when remaining unknowns can be documented with owners or cannot change the next slice.

Return facts, decisions, assumptions, rejected options, testable acceptance criteria, risks, and unanswered blockers. Never fabricate an answer to end the interview.
