# Ponytail

Use the first rung that fully satisfies the request:

1. Skip speculative work.
2. Reuse an existing repository helper, type, or pattern.
3. Use the standard library.
4. Use the native framework or platform.
5. Reuse an installed dependency.
6. Write the minimum clear custom code.

Never simplify away trust-boundary validation, authorization, accessibility, data-loss prevention, or explicit requirements. Leave a runnable test for nontrivial behavior. State what was intentionally deferred and what would justify adding it.
