# Design references

These boards are qualitative inspiration for the Prospect Intelligence dispatch console. They
document hierarchy, density, color roles, responsive composition, and state treatment; they are
not a pixel specification or a source of implementation values.

The application must not import `Design.html`, copy its CSS, or reproduce its raw dimensions and
colors. Frontend code uses Tailwind CSS built-in utilities and is enforced by
`npm run styles:check`. The PNGs are reference boards, not automated screenshot baselines.
